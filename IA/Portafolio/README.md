# Portafolio Web Profesional - Yoinser León
### Programador Web Full-Stack Senior

Bienvenido al repositorio oficial del portafolio web personal de **Yoinser León**, desarrollado con **Next.js (App Router)**, **React**, **Tailwind CSS**, **TypeScript** y gestionado exclusivamente con **pnpm**.

---

## 🌅 Estética y Concepto Visual
El diseño está inspirado en un portafolio moderno de tono oscuro con una paleta cálida personalizada que armoniza de forma orgánica con la fotografía de perfil de iluminación al atardecer:
- **Colores Base**: Negro obsidiana, pizarra y carbón profundo (`#060910`, `#070a12`, `#0b0f1b`).
- **Acentos y Luces**: Tonos ámbar dorado, naranja cálido y destellos crepusculares (`#f59e0b`, `#ea580c`, `#fbbf24`).
- **Estética de Proyectos**: Ilustraciones y capturas de alta definición en **Pixel Art**, aportando identidad visual retro-moderna única.

## 🚀 Comandos del Proyecto (Exclusivamente con `pnpm`)

```bash
# 1. Instalar dependencias
pnpm install

# 2. Iniciar servidor de desarrollo local
pnpm dev

# 3. Compilar para producción (Next.js Turbopack)
pnpm build

# 4. Iniciar en modo producción
pnpm start
```
